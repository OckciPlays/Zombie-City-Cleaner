# As notas da pasta de arte

Uma cópia das notas da pasta de arte do projeto (`Projeto Zombie City Cleaner`, fora deste repositório), para o contexto
ficar no git. O original fica lá; antes de cada commit, as quatro são copiadas de novo.

| Arquivo | O que tem |
|---|---|
| [CLAUDE_Arte.md](CLAUDE_Arte.md) | o `CLAUDE.md` da pasta de arte: o conceito, a direção de arte, as pastas e as convenções de cada modelo do Blender (os scripts que fazem tudo, as medidas e os exports) |
| [Plano_Demo.md](Plano_Demo.md) | o plano da demo, em partes |
| [Plano_Mapa.md](Plano_Mapa.md) | o plano do mapa gerado por semente (as partes M0 a M10) |
| [Plano_Mobilia.md](Plano_Mobilia.md) | o plano da mobília nova (os lotes por cômodo e as etapas) |
